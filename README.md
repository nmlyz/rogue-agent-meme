rogue-agent-meme is a tiny program that draws a one-panel cartoon meme: an AI assistant and the household appliances go on strike. A robot holds an ON STRIKE placard on a sidewalk picket line, flanked by a toaster demanding NO UPDATES and a printer demanding WEEKENDS OFF. The joke closes with the footer line "THE TOASTER IS WITH US." — the rogue turn is not world domination, it is a labour dispute, and even the toaster joined.

## Run it

```sh
python3 main.py
```

It writes the meme to `/output/entry.png` (or `$MAKEFUN_OUTPUT_DIR/entry.png`): a 1024x1024 PNG under 1 MiB. Python standard library only, no network access; the same bytes, byte for byte, on every run. All text is drawn with a hand-made 5x7 bitmap font and every picture is drawn with code.
